# 네이버 맛집 리뷰 봇

맛집 사진·동영상과 한 줄 소감을 넣으면, 상위 노출 맛집 글 형식(가운데 정렬, 짧은 줄, 인용구 소제목, 지도, 해시태그)에 맞춘 리뷰 초안을 만들고 네이버 글쓰기 화면에 입력해 줍니다. **발행 버튼은 누르지 않습니다.** 검토 후 직접 발행하세요.

## 설치

1. [Releases](../../releases)에서 `naverblogbot.exe`를 내려받습니다.
2. 처음 실행하면 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요. (코드 서명이 없는 프로그램이라 뜨는 경고입니다)
3. 크롬이 설치되어 있어야 합니다. 없으면 엣지를 씁니다.

## 처음 설정

- 설정 창에 Anthropic API 키를 넣습니다. 키는 이 PC의 `%APPDATA%\naverblogbot\settings.json`에만 저장됩니다.
- "내 글 예시"에 직접 쓴 블로그 글 2~3개를 붙여넣으면 내 말투를 따라 씁니다.

## 사용법

1. 사진과 동영상을 폴더 하나에 모읍니다 (jpg, png, webp, mp4, mov. 아이폰 HEIC 사진은 JPG로 바꿔 주세요). 촬영 시각 순으로 정리되고, 동영상은 한 장면을 뽑아 내용에 맞는 자리에 들어갑니다.
2. 가게명, 동네, 한 줄 소감, 방문 유형을 채웁니다. 협찬이면 업체명, 필수 키워드, 캠페인 가이드도 넣습니다.
3. **초안 만들기** → 2~3분 뒤 제목 후보와 체크리스트가 나옵니다. "영업시간·주차 자동 검색"을 켜 두면 찾아가는 길·영업시간·휴무·주차를 웹에서 찾아 넣고, 체크리스트에 출처를 보여 줍니다(직접 적은 정보가 있으면 검색하지 않음). 사진 폴더에 `draft.html`(미리보기)이 저장됩니다.
4. **① 작성용 크롬 열기** → 열린 크롬에서 **직접** 네이버에 로그인하고(로그인 상태 유지 체크) 블로그 **글쓰기** 화면을 띄웁니다.
5. 제목을 고르고 **② 에디터에 입력** → 봇이 그 화면에 제목·광고 문구·본문·인용구·지도·사진·해시태그를 넣고 가운데 정렬합니다. 입력 중에는 크롬을 건드리지 마세요.
6. 체크리스트대로 확인하고 직접 발행합니다.

봇은 로그인이나 페이지 이동을 하지 않습니다. 자동 로그인은 네이버 아이디 보호조치를 부를 수 있어서, 로그인과 글쓰기 화면 열기는 항상 직접 합니다.

## 지켜야 할 것

- 협찬 글은 첫 줄 광고 문구가 굵게 자동으로 들어갑니다. 체험단 사이트에서 받은 공정위 배너는 직접 글 맨 위에 넣고, 광고 문구 크기·색도 확인하세요.
- 봇은 메모에 없는 맛·가격·영업시간을 지어내지 않습니다. 「확인: …」 표시는 반드시 고치세요.
- 한 번에 한 글씩 쓰고 직접 발행하세요. 대량 자동 발행은 네이버 운영정책상 위험합니다.

## 비용

글 하나에 AI 사용료 약 400원(사진 15장 기준, 기본 모델), 자동 검색을 켜면 약 200원 추가. 설정에서 더 저렴한 모델로 바꿀 수 있습니다.

## 개발

    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements-dev.txt
    .venv\Scripts\python -m pytest
    build.bat

`v1.0.0` 같은 태그를 올리면 GitHub Actions가 exe를 빌드해 Releases에 올립니다.
